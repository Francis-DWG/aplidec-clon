# Aplidec Clon

Clon estático completo del sitio web aplidec.com - Pinturas y Revestimientos Profesionales.

## Estructura del Proyecto

```
aplidec-clon/
├── index.html                                    # Página de inicio
├── aplicaciones-para-interior.html               # Aplicaciones para interior
├── aplicaciones-para-exterior.html               # Aplicaciones para exterior
├── acabados.html                                 # Acabados profesionales
├── clientes.html                                 # Lista de clientes
├── proyectos.html                                # Galería de proyectos
├── contacto.html                                 # Formulario de contacto
├── blog.html                                     # Blog
├── politicas-de-privacidad.html                  # Política de privacidad
├── aplicaciones-para-exterior/
│   ├── corcho-proyectado-aislamiento-natura.html # Corcho proyectado
│   └── pintura-anti-radon.html                   # Pintura anti-radón
├── css/
│   └── styles.css                                # Estilos principales
├── js/
│   └── main.js                                   # JavaScript principal
└── assets/
    └── img/
        └── gallery/                              # Imágenes de proyectos
```

## Páginas Implementadas

- **Inicio** (`index.html`): Hero section, tarjetas de servicios interior/exterior, sección "Nuestros Servicios"
- **Aplicaciones para Interior** (`aplicaciones-para-interior.html`): Comunidades, hoteles, naves industriales, reparación de grietas, parkings
- **Aplicaciones para Exterior** (`aplicaciones-para-exterior.html`): Protección de fachadas, pinturas al silicato, corcho proyectado, impermeabilización
- **Acabados** (`acabados.html`): Esmaltes, silicato, super-lavable, anti-bacterias, efecto hormigón, papel pintado, acero corten, techo registrable, Magic Light
- **Clientes** (`clientes.html`): Lista de clientes y empresas
- **Proyectos** (`proyectos.html`): Galería de imágenes de trabajos realizados
- **Contacto** (`contacto.html`): Formulario de contacto, información de contacto, enlaces a redes sociales
- **Blog** (`blog.html`): Artículos y noticias
- **Política de Privacidad** (`politicas-de-privacidad.html`): Información legal sobre tratamiento de datos
- **Corcho Proyectado** (`aplicaciones-para-exterior/corcho-proyectado-aislamiento-natura.html`): Información sobre aislamiento natural
- **Pintura Anti-Radón** (`aplicaciones-para-exterior/pintura-anti-radon.html`): Barrera contra gas radón

## Características

- Diseño responsive (desktop y móvil)
- Menú de navegación con submenús desplegables
- Menú móvil hamburguesa
- Banner de cookies con opciones (Aceptar/Rechazar/Configurar)
- Formulario de contacto funcional
- Galería de proyectos
- Estructura semántica HTML5
- CSS moderno con variables y flexbox/grid
- JavaScript vanilla para interacciones

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, Variables CSS)
- JavaScript (Vanilla)
- Font Awesome (iconos)
- Google Fonts (Montserrat)

## Uso

1. Abrir `index.html` en un navegador web
2. Navegar entre las diferentes páginas usando el menú de navegación
3. El sitio es completamente estático, no requiere servidor

## Notas

- Las imágenes de proyectos en la galería son placeholders que deben ser reemplazadas con las imágenes reales del sitio original
- El formulario de contacto es simulado (muestra alerta al enviar)
- El banner de cookies guarda la preferencia en localStorage
